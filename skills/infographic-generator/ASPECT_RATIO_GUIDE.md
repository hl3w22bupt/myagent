# Infographic 长宽比智能推荐系统

## 📐 概述

新的长宽比推荐系统会根据**内容类型**、**项目数量**和**目标平台**自动选择最合适的尺寸，确保生成的信息图美观、统一。

## 🎯 核心优势

### 1. **智能适配**
- ✅ 根据内容类型自动选择最佳比例
- ✅ 根据项目数量调整尺寸
- ✅ 避免手动选择不当导致的视觉问题

### 2. **视觉一致性**
- ✅ 同类内容使用统一的长宽比
- ✅ 避免信息图尺寸混乱
- ✅ 提升整体视觉体验

### 3. **平台优化**
- ✅ 支持 Instagram、Twitter、LinkedIn、微信等平台
- ✅ 针对不同平台使用最佳尺寸
- ✅ 提高社交媒体分享效果

## 📊 推荐规则

### 按内容类型

| 内容类型 | 项目数 | 推荐比例 | 尺寸示例 | 说明 |
|---------|-------|---------|---------|------|
| **sequence** (流程/序列) | ≤4 | 16:9 | 1920×1080 | 标准宽屏 |
| | 5-8 | 21:9 | 2560×1080 | 超宽屏，展示更多步骤 |
| | >8 | 21:9 | 2560×1080 | 超宽屏，适合长流程 |
| **list** (列表) | ≤4 | 1:1 | 1080×1080 | 正方形，紧凑美观 |
| | 5-8 | 16:9 | 1920×1080 | 标准宽屏 |
| | >8 | 3:4 | 1080×1440 | 竖版，适合移动端 |
| **chart** (图表) | 任意 | 16:9 | 1920×1080 | 标准宽屏 |
| **quadrant** (四象限) | 任意 | 1:1 | 1080×1080 | 正方形，完美对称 |
| **compare** (对比) | 任意 | 16:9 | 1920×1080 | 宽屏，便于并排对比 |
| **hierarchy** (层级) | ≤6 | 16:9 | 1920×1080 | 标准宽屏 |
| | >6 | 21:9 | 2560×1080 | 超宽屏，展示复杂结构 |

### 按目标平台

| 平台 | 推荐比例 | 尺寸 | 用途 |
|------|---------|------|------|
| **Instagram** | 1:1 | 1080×1080 | 信息流 |
| | 9:16 | 1080×1920 | Stories |
| **Twitter** | 16:9 | 1920×1080 | 信息流 |
| | 1:1 | 1080×1080 | 时间线 |
| **LinkedIn** | 4:3 | 1440×1080 | 信息流 |
| | 1:1 | 1080×1080 | 文档 |
| **微信** | 1:1 | 1080×1080 | 朋友圈 |
| | 3:4 | 1080×1440 | 公众号文章 |
| **Default** | 16:9 | 1920×1080 | 通用场景 |

## 💻 使用方法

### 基础使用（自动推荐）

```python
# 用户只需提供内容，系统自动推荐最佳尺寸
input_data = {
    "content": "1. 需求分析\n2. 系统设计\n3. 代码开发\n4. 测试部署\n5. 上线运维",
}

# 系统自动识别：
# - 内容类型: sequence
# - 项目数量: 5
# - 推荐尺寸: 2560×1080 (21:9 超宽屏)
```

### 指定平台

```python
# 针对特定平台优化
input_data = {
    "content": "产品特性列表...",
    "platform": "instagram",  # 指定平台
}

# 系统推荐：
# - 尺寸: 1080×1080 (1:1 正方形)
# - 适合 Instagram 信息流
```

### 自定义尺寸

```python
# 用户可以完全自定义尺寸
input_data = {
    "content": "...",
    "width": 1920,
    "height": 1080,
}

# 使用用户指定的尺寸
```

### 部分自定义

```python
# 只指定宽度或高度，系统自动计算另一边
input_data = {
    "content": "...",
    "width": 1920,  # 只指定宽度
}

# 系统根据推荐比例计算高度
# 例如：如果推荐 16:9，则高度 = 1920 × 9 / 16 = 1080
```

## 📈 效果对比

### 优化前 ❌
```
用户输入相同类型内容，但尺寸混乱：
- 1920×1080 (16:9)
- 1080×1080 (1:1)
- 2560×1080 (21:9)
- 1080×1920 (9:16)

→ 视觉不统一，显得杂乱无章
```

### 优化后 ✅
```
系统智能推荐，尺寸统一：
- 流程类 (5项) → 2560×1080 (21:9)
- 列表类 (6项) → 1920×1080 (16:9)
- 列表类 (3项) → 1080×1080 (1:1)

→ 视觉统一，专业美观
```

## 🎨 最佳实践

### 1. **信任自动推荐**
- 大多数情况下使用系统推荐的尺寸
- 系统基于大量数据和视觉设计原则

### 2. **考虑目标平台**
- 如果主要在特定平台发布，指定 platform 参数
- 不同平台的最佳尺寸不同

### 3. **保持一致性**
- 同一系列内容使用相同的长宽比
- 有助于建立统一的视觉风格

### 4. **移动优先**
- 如果不确定，选择竖版或正方形
- 更适合移动设备查看
