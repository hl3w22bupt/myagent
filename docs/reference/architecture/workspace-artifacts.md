# Workspace 和 Artifacts 系统

> 统一的 Workspace 管理和 Artifacts 产物追踪

**阅读时间**: 8 分钟 | **难度**: ⭐⭐ intermediate

---

## 🎯 概述

MyAgent 使用统一的 Workspace 标准和 Artifacts 产物系统，确保所有 Agent（内置 Agent、ExternalAgent、Workflow）共享一致的文件管理方式。

### 核心能力

- ✅ **统一 Workspace**: 四级优先级解析，所有 Agent 共享同一 workspace
- ✅ **Artifacts 追踪**: 自动收集和分类任务产出文件
- ✅ **前端展示**: Workspace Tab 实时展示文件列表和预览
- ✅ **自动清理**: 默认 workspace 任务完成后自动清理

## 📁 Workspace 标准

### 目录结构

```
Task Level Workspace（所有 Agent 和 Skill 共享）
├── 默认: /tmp/myagent-workspace/{taskId}/
├── 自定义: {user-specified-path}/
└── 生命周期: 随 task 创建，task 结束后根据规则清理
```

### 优先级解析

Workspace 路径按以下优先级解析（`resolveWorkspace()` 函数）：

| 优先级 | 来源 | 说明 |
|--------|------|------|
| 1 | `context.environment.workspace` | 用户通过 API 显式指定 |
| 2 | `context.environment.workingDirectory` | 向后兼容字段 |
| 3 | Agent 配置的 `workingDirectory` | Agent 默认值 |
| 4 | `/tmp/myagent-workspace/{taskId}/` | 系统自动生成 |

### 使用示例

```bash
# 显式指定 workspace
curl -X POST http://localhost:3000/agent/execute \
  -H "Content-Type: application/json" \
  -d '{
    "task": "创建一个 Python 脚本",
    "sessionId": "test-session",
    "environment": {
      "workspace": "/Users/leo/my-project"
    }
  }'
```

### 清理规则

| Workspace 类型 | 来源判断 | 清理策略 |
|---------------|---------|---------|
| 自动生成 | 用户未指定 `environment.workspace` | 任务完成后自动删除 |
| 用户指定 | 用户指定了 `environment.workspace` | 永久保留 |

判断依据是 `workspaceAutoGenerated` 标记（存储在 WorkflowContext 中），**不依赖路径前缀**。

### 各层 Workspace 传递

```
API 请求 (environment.workspace)
    ↓
MasterAgent (context.environment.workspace)
    ↓
WorkflowEngine (resolveWorkspace → workflowWorkspace)
    ↓
Agent.run() (context.environment.workspace)
    ↓
Sandbox (metadata.workspace → WORKSPACE 环境变量)
    ↓
Python Skill (os.environ['WORKSPACE'])
```

## 📦 Artifacts 产物系统

### 数据结构

```typescript
interface AgentArtifacts {
  workspace: string;              // workspace 绝对路径
  files: Record<string, FileArtifact[]>;  // 按类型分类
  allFiles: FileArtifact[];       // 所有文件列表
  summary: {
    counts: Record<string, number>;
    totalFiles: number;
    totalSize: number;
  };
}

interface FileArtifact {
  type: ArtifactType;    // videos | images | audios | codes | documents | data | other
  path: string;          // 绝对路径
  name: string;          // 文件名
  relativePath: string;  // 相对于 workspace 的路径
  operation: 'created' | 'modified' | 'deleted';
  size: number;          // 文件大小（bytes，从磁盘读取）
}
```

### 文件类型分类

| 类型 | 扩展名 |
|------|--------|
| videos | `.mp4`, `.mov`, `.avi`, `.webm`, `.mkv` |
| images | `.png`, `.jpg`, `.jpeg`, `.gif`, `.svg`, `.webp` |
| audios | `.mp3`, `.wav`, `.aac`, `.m4a`, `.ogg` |
| codes | `.py`, `.js`, `.ts`, `.json`, `.yaml`, `.html`, `.css`, `.md` 等 |
| documents | `.pdf`, `.doc`, `.docx`, `.ppt`, `.pptx` |
| data | `.csv`, `.tsv`, `.sql` |

### Artifacts 来源

**内置 Agent** (`agent.ts`):
- 从 `structuredOutputs[].output_files` 构建
- `buildArtifactsFromOutputFiles()` 方法

**ExternalAgent** (`external-agent.ts`):
- 从 ACP `tool_call` 事件的文件操作构建
- `ArtifactCollector.fromFileOperations()` 转换
- 文件大小通过 `fs.statSync` 从磁盘读取

## 🔌 Workspace API

### 获取 Workspace 文件列表

```
GET /api/workspace/:taskId
```

**Workspace 查找优先级**:

| 优先级 | 路径 | 适用场景 |
|--------|------|---------|
| 1 | `metadata.workspace` | 直接 Agent 任务 |
| 2 | `metadata.environment.workspace` | 通过 environment 传入 |
| 3 | `metadata.variables.workflowWorkspace` | Workflow 任务 |
| 4 | `metadata.variables.variables.workspace` | 嵌套变量 |

**响应**:

```json
{
  "success": true,
  "data": {
    "taskId": "task-xxx",
    "workspace": "/tmp/myagent-workspace/task-xxx",
    "files": [
      {
        "name": "hello.py",
        "path": "/tmp/myagent-workspace/task-xxx/hello.py",
        "size": 21,
        "type": "file",
        "relativePath": "hello.py"
      }
    ],
    "summary": {
      "fileCount": 1,
      "dirCount": 0,
      "totalSize": 21
    }
  }
}
```

## 🖥️ 前端 Workspace Tab

### 实时刷新

- 任务执行中每 5 秒自动轮询 workspace 文件列表
- 任务完成后停止轮询
- 用户可手动点击刷新按钮

### 文件预览

- 文本文件：代码高亮预览（CodePlayer）
- 图片：内联展示
- 视频/音频：播放器
- 二进制文件：下载链接
