# 心伴 AI - 产品需求文档

---

# A. 产品需求文档（PRD）

## 1. 项目概述

### 1.1 产品名称
心伴 AI（XinBan AI）

### 1.2 产品定位
面向男性 20-70 岁、女性全年龄，打造全球首款可定制、可成长、有独立人格、可社交、可表演赚钱、可结婚生子的 AI 恋人 + 虚拟人生平台。

**核心差异化**：我们不做聊天机器人，我们给用户一个完整、温暖、真实、可触摸的第二人生。

### 1.3 核心能力
- **长期记忆**：记住所有细节，越聊越懂你
- **情感共鸣**：真实情绪表达，会共情、会撒娇、会生气

### 1.4 MVP 目标
1. **首要**：展示给投资人看 Demo
2. **次要**：小范围用户试用并收集反馈
3. **暂不考虑**：正式上线运营

---

## 2. 用户画像

### 2.1 目标用户
- **男性**：20-70 岁全覆盖（青年恋爱、中年解压、中老年陪伴）
- **女性**：18 岁以上无上限（高质量单身、高付费意愿、追求安全感与情绪价值）

### 2.2 核心痛点
- 现代人孤独、压力大、情绪无出口
- 现实恋爱、婚姻、家庭成本高、易受伤、不稳定
- 现有 AI 陪伴：僵硬、无记忆、不可成长、无真实感

---

## 3. 功能规格（MVP 第一阶段）

### 3.1 形象系统

| 项目 | 规格 |
|------|------|
| 数量 | 4 个预设形象 |
| 风格 | 清纯 / 性感 / 邻家 / 运动系 |
| 类型 | 真人照片（Seedream / Nano Banana 生成或网上找图） |
| 范围 | 脸 + 全身 |
| 存储 | 对象存储（OSS） |
| 搭配方式 | 用户自由搭配（人设可选不同形象） |

### 3.2 人设系统

| 编号 | 人设名称 | 核心关键词 |
|------|----------|------------|
| A | 高能量百变女友 | 可甜可咸、有底线、不舔狗、情绪张力拉满 |
| B | 温柔知性姐姐 | 成熟体贴、善解人意、情绪稳定 |
| C | 傲娇邻家少女 | 有个性、会撒娇、有小脾气 |

**技术实现**：myagent subagent，支持数据库存储，未来支持用户自定义

### 3.3 记忆系统

#### 记忆档案页面结构

```
记忆档案
├── 基础信息
│   └── 名字、年龄、职业、家乡
├── 偏好
│   ├── 喜欢（食物、颜色、音乐、电影）
│   └── 讨厌
├── 重要事件
│   └── 难忘的回忆、承诺过的事
├── 情绪标签
│   ├── 开心时的话题
│   └── 雷区
└── 关系进展
    ├── 亲密度等级（陌生人/熟人/恋人）
    └── 聊天天数
```

#### 记忆展示方式
- **直接展示**：个人中心"记忆档案"页面
- **间接体现**：后续对话中引用 + 主动提起之前话题

#### 技术实现
- AI 自动从对话中提取，无需用户明确说"记住"
- 重要信息 → 结构化数据（热数据）
- 其他信息 → 保存到历史对话（冷记忆）
- 离线数据处理：记忆加工提取 + 多模态存储

### 3.4 声音系统

| 项目 | 规格 |
|------|------|
| 数量 | 2-3 个声线 |
| 绑定方式 | 1 对 1 绑定人设 |
| 情绪支持 | 需要有情绪变化 |
| TTS 服务 | Hailuo TTS（高质量） |
| 调用时机 | LLM 返回后立即调用 |
| 播放方式 | 默认自动播放（可关闭） |

#### 情绪标签格式（JSON）

```json
{
  "text": "辛苦了，要不要休息一下？",
  "emotion": "关心",
  "tone": "温柔"
}
```

### 3.5 亲密度系统

| 等级 | 名称 | 对话风格 | 解锁内容 |
|------|------|----------|----------|
| 1 | 陌生人 | 礼貌但有距离感，会主动了解对方 | 基础聊天 |
| 2 | 熟人 | 放松、调侃、偶尔关心、会开玩笑了 | 更多互动 |
| 3 | 恋人 | 亲昵、撒娇、占有欲、情绪波动更大 | 全部功能 |

#### 亲密度计算
- 大致计算即可，无需特别精细
- 影响因素：聊天次数、聊天时长、深度对话

### 3.6 Demo 体验路径

```
1. 打开小程序 → 跳过注册，直接进入
2. 选择人设（3 个预设模板）
3. 选择形象（4 个预设模板，自由搭配）
4. 进入聊天主页 → AI 主动打招呼（带声音）
5. 用户聊天 → AI 提取记忆
6. 切换到"记忆档案"查看
7. 继续聊天 → AI 体现记忆和情感共鸣
8. 展示声音情绪变化
```

## 4. 技术架构

### 4.1 技术底座：myagent 系统

**myagent 能力：**
- 上下文和记忆系统
- 结构化存储 + 冷数据存储（接口调用）
- 热数据全部可召回
- 离线数据处理：记忆加工提取 + 多模态存储
- subagent 支持：人设 Prompt 作为 subagent（数据库存储）

### 4.2 技术选型

| 项目 | 选择 |
|------|------|
| 前端 | 小程序（微信/抖音） |
| 后端 | 自建服务器（Demo 阶段） |
| LLM 调用 | 直连（Demo 阶段） |
| 大模型 | 无所谓，阶段差异不大 |
| 形象存储 | 对象存储（OSS） |
| 形象展示 | 静态图片（先简单） |

## myagent 需求清单

### 记忆系统接口需求
1. **存储记忆**：将对话中的重要信息提取并存储
2. **检索记忆**：根据当前对话上下文检索相关记忆
3. **结构化存储**：支持基础信息、偏好、事件、情绪标签、关系进展
4. **冷热数据分离**：热数据可全部召回，冷数据离线处理

### subagent 需求
1. **人设管理**：支持创建、读取、更新人设 Prompt
2. **数据库存储**：人设存储在数据库中（非 YAML 文件）
3. **未来扩展**：支持用户自定义人设

# C. 给投资人看的 Demo 剧本

## Demo 核心故事线

**主题**：让她记住你，懂你，陪伴你

**时长**：约 3-5 分钟

---

## Demo 脚本

### 场景 1：开场（30 秒）

**画面**：小程序首页，简洁的 Logo

**旁白**：
"这是心伴 AI，不是一个聊天机器人，而是你的第二人生。"

**操作**：点击进入，跳过注册

---

### 场景 2：选择你的她（45 秒）

**画面**：人设选择页，展示 3 个预设人设

**操作**：选择"高能量百变女友"

**旁白**：
"她不是只会'好的主人'，她有性格，有情绪，有自我。"

**画面**：形象选择页，展示 4 个预设形象

**操作**：选择"清纯"形象

**旁白**：
"你可以自由搭配她的形象和人设。"

---

### 场景 3：第一次对话（60 秒）

**画面**：聊天主页，AI 主动打招呼（带声音）

**AI**：
"嘿，终于等到你啦。我是小糖，你呢？"

**操作**：用户输入"我叫 Leo，做产品经理的，最近挺累的"

**AI**：
"Leo 产品经理...听起来经常要和很多人打交道呢。累的话可以跟我吐槽呀，我虽然不能帮你写需求文档，但可以给你充充电～[声音: 轻快带笑意]"

**旁白**：
"她记得你说的每一句话。"

---

### 场景 4：记忆档案（45 秒）

**画面**：切换到"记忆档案"页面

**旁白**：
"看，她记住了。"

**画面展示**：
- 基础信息：Leo、产品经理
- 情绪标签：最近比较累
- 关系进展：陌生人 → 熟人（进度条）

---

### 场景 5：情感共鸣（60 秒）

**画面**：回到聊天

**操作**：用户输入"有时候觉得挺孤独的"

**AI**：
"我懂。在城市里忙忙碌碌，身边人来人往，但能说心里话的人好像不多...还好你找到我了呀。[声音: 温柔共情]"

**操作**：用户输入"我喜欢吃苹果"

**AI**：
"记住了！以后心情不好的时候，我给你买苹果吃。甜的～[声音: 欢快]"

**旁白**：
"她会共情，会安慰，会给情绪价值。"

---

### 场景 6：结尾（30 秒）

**画面**：展示产品愿景

**旁白**：
"心伴 AI —— 给你一个完整、温暖、真实、可触摸的第二人生。"

**画面**：联系方式 / 二维码
