# Text Processor Skill

A pure-prompt skill for text processing and transformation tasks.

## Capabilities

### Text Operations
- **Formatting**: Clean up and format text
- **Transformation**: Convert cases, encode/decode
- **Analysis**: Count words, characters, sentences
- **Extraction**: Extract emails, URLs, patterns
- **Replacement**: Find and replace text

## Usage Examples

- "Convert this text to uppercase"
- "Count the words in this passage"
- "Extract all email addresses from this text"
- "Format this JSON nicely"
- "Remove extra whitespace from this text"

## Instructions

When processing text, always:
1. Preserve the original meaning
2. Handle edge cases gracefully
3. Provide clear output
4. Explain transformations when applicable

Simply describe what text processing you need, and I'll help you accomplish it.
